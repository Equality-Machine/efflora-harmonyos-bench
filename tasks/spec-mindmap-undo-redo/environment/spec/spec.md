# 节点编辑页支持撤销 / 重做与节点计数

为演示应用"节点编辑"页的编辑操作（加子级、加同级、删除、修改）提供撤销与重做，并实时显示节点总数。撤销/重做能力由组件库提供，演示页只负责调用和展示。

场景1：进入"节点编辑"页，导图上方的操作区显示一行独立文字"共 6 个节点"（含中心主题，格式固定为"共 N 个节点"），以及新增的"撤销""重做"按钮，两者均为禁用状态（灰显、不可点击）。在默认选中中心主题、输入框为空时点击"加子级"，导图出现"新子节点"，计数变为"共 7 个节点"，"撤销"可用，"重做"仍禁用。

场景2：点击"加子级"（新节点自动选中），在输入框输入"Renamed"并点击"修改"，该节点显示为"Renamed"。点击"撤销"：节点恢复为"新子节点"，"Renamed"不再出现，计数仍为"共 7 个节点"，两个按钮都可用。再点击"撤销"："新子节点"消失，计数恢复为"共 6 个节点"，"撤销"禁用，"重做"可用。

场景3：接场景2，点击"重做"：重新出现"新子节点"，计数"共 7 个节点"，两个按钮都可用；再点击"重做"：节点变为"Renamed"，"重做"禁用，"撤销"可用。

场景4：在导图中点击"复杂子树 A"并点击"删除"：它和全部后代（"a1 深层分支""a11 更深层""a2 子节点"）消失，计数"共 2 个节点"。点击"撤销"：四个节点全部恢复，层级和兄弟顺序与删除前一致（"复杂子树 A"仍在"叶子 B"之前），计数"共 6 个节点"，"撤销"禁用，"重做"可用。随后点击"加子级"，出现"新子节点"，计数"共 7 个节点"，"重做"立即禁用（新编辑清空重做历史）。

约束：撤销后选中态回到该次编辑前的节点，重做后回到编辑后的节点；点选节点、撤销、重做本身不产生历史记录。键盘快录（回车、Tab、空输入按 Delete）同样进入历史；撤销后新建节点的 id 不得与已有节点重复。不得破坏已有编辑功能，沿用现有按钮样式。
