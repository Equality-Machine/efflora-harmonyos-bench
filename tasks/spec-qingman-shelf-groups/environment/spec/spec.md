# 书架分组

青漫阅读器的书架只是平铺网格，书多了无法归类。请为"书架"页面增加分组功能：支持创建分组、把书移入分组、按分组浏览和管理分组。已有的书架数据必须保持兼容，原有书籍照常显示，默认属于"未分组"。

场景1：创建分组。书架页顶部标题"书架"所在的一行新增文字按钮"分组"，点击后进入标题为"书架分组"的页面。该页面始终提供"新建分组"按钮；没有任何分组时，页面显示"还没有分组"。点击"新建分组"弹出标题为"新建分组"的对话框，内含一个输入框（占位文字"分组名称"）以及"取消"、"确定"两个按钮。输入名称并点击"确定"后，新分组出现在列表中，每行显示分组名称和该分组的书籍数量，格式为"N 本"（如"0 本"）。名称为空或与已有分组重名时不创建。

场景2：把书移入分组。在书架上长按一本书，弹出的操作菜单在原有选项之外新增"移动到分组"。点击后弹出标题为"移动到分组"的选择列表，列出所有分组名称以及"未分组"。选择某个分组后，这本书即归入该分组（一本书同一时间只属于一个分组），"书架分组"页面中该分组的数量相应变化（如"1 本"）。

场景3：按分组浏览。至少存在一个分组时，书架标题行下方显示一行分组标签：依次为"全部"、按创建顺序排列的各分组名称、"未分组"。默认选中"全部"并显示所有书；点击某个分组只显示该分组的书；点击"未分组"只显示不属于任何分组的书；点击"全部"恢复显示全部书籍。没有分组时不显示这一行，书架与原来一致。

场景4：重命名与删除。"书架分组"页面每个分组行都有"重命名"和"删除"两个文字按钮。点击"重命名"弹出标题为"重命名分组"的对话框，输入框中预填原名称，修改后点击"确定"即生效：原分组中的书仍属于该分组，书架上的分组标签同步显示新名称。点击"删除"先弹出确认（按钮"取消"/"删除"），确认后删除该分组，其中的书回到"未分组"。

约束：分组及书籍归属在完全退出并重新打开应用后依然保留；不得破坏书架原有的阅读、置顶、移出书架功能；沿用应用现有的标题栏和配色风格。
